# Data Screenshots — Clipboard Captures

## Purpose
Images captured from clipboard via `scripts/clip2file.ps1` for analysis in Cascade.

## How to Add
1. `Win+Shift+S` → snip region
2. Run `.\scripts\clip2file.ps1` (path auto-copied to clipboard)
3. Paste path into Cascade chat → `read_file` displays the image

## Naming Convention
`snip_YYYYMMDD_HHMMSS.png` — auto-generated timestamp.

## Note
These screenshots are **project context** — UI mockups, error screenshots, test results,
reference images, etc. They are part of the project data and should be referenced by
Planner/Cascade when working on related tasks.
